# BPMN ⇄ yEd GraphML 合并转换器

把多个 BPMN 2.0 流程文件合并为一张图，在 yEd Graph Editor 里自动布局（也可以手工编辑），然后转回 BPMN。转回时有两种方式：

- **合并模式**：输出一个合并后的大流程文件；
- **拆分模式**：拆回原来的每个文件，所有原 ID 保持不变，只是布局换成 yEd 排好的。

## 环境要求

- Python 3.10 或更高版本（只用标准库，无需安装第三方包）
- [yEd Graph Editor](https://www.yworks.com/products/yed)（已在 3.25.1 上验证）

## 启动

```bash
python -m bpmn2graphml            # 打开图形界面
```

命令行用法：

```bash
# 1. 合并多个 BPMN → graphml（同时生成 merged.merge-report.txt 合并报告）
python -m bpmn2graphml merge 科技创新平台策划.bpmn 科技创新平台申报.bpmn -o merged.graphml

# 2. yEd 保存后 → 转回 BPMN（两种方式可以只选一种，也可以都选）
python -m bpmn2graphml tobpmn merged.graphml --merged merged.bpmn --split 拆分输出/
```

## 在 yEd 中的操作

1. 用 yEd 打开生成的 `.graphml`。节点会显示为 yEd 自带的 BPMN 图形。
2. 菜单 **布局 › 分层**（Layout › Hierarchical），按需要调整参数后应用。
3. 可以修改节点或连线的名称，也可以删除元素。新增节点时，请从右侧面板的 **BPMN** 分组里拖入，这样程序才能识别它是任务、网关还是事件；其它普通图形一律当作“任务”处理。
4. **文件 › 保存**，保持 `.graphml` 格式（不要另存为 `.graphmlz`）。
5. 回到本程序，把保存好的 graphml 转回 BPMN。

## 合并规则

| 情况 | 处理方式 |
|---|---|
| 不同文件中名称完全相同的节点 | 合并成一个节点，所有连线都接到它上面；沿用最先出现的那个节点的 ID |
| A 的结束事件与 B 的开始事件同名 | 合并后，在合并模式中改为中间事件；拆分模式中恢复原类型 |
| 空的子流程，且有同名文件 | 展开为该文件的内容：入线接到它的开始事件，出线从它的结束事件引出 |
| 名称为空的节点（例如网关） | 从不参与合并 |
| 同一文件中的同名节点 | 不合并（报告中会给出警告） |
| 不同文件中 ID 相同、但不是同一节点 | 合并模式中改名为 `原ID_2`，拆分模式中保持原 ID |

每次合并都会生成 `*.merge-report.txt`，列出所有合并、展开和警告，请检查一遍，确认没有误合并。

拆分模式中，在 yEd 里新增的节点会归入与它相连节点所在的文件；跨越不同文件的新增连线无法归入任何单个文件，会被跳过，并在警告中列出。

## 可视化查看器

用来在浏览器中浏览一个 BPMN 流程（合并前或合并后的都可以），并**按节点属性筛选、高亮**。

```bash
python -m bpmn2graphml view merged.bpmn   # 直接打开指定文件
python -m bpmn2graphml view               # 打开空白查看器，再点「打开 BPMN」或把文件拖进页面
```

图形界面中：「GraphML → BPMN」页签的「在查看器中打开」会打开刚转换出的合并文件；窗口底部的「打开可视化查看器」会打开空白查看器。也可以直接双击 `bpmn2graphml/viewer/index.html`。

使用方法：

1. 在顶部「筛选类别」下拉框中选一个属性，例如「来源流程」「元素类型」；「清除筛选」位于下拉框旁。文件操作、适应窗口和导出按钮位于最上方，具体筛选取值标签在其下方单独排列。
2. 点击一个或多个取值标签，标签上的数字是节点数。不同取值各有固定的颜色，匹配的节点使用对应标签的颜色高亮，其余节点变淡；两端都高亮的连线保持正常显示。同时匹配多个已选取值的节点使用分段底色，详情卡中会列出「当前匹配」的取值。筛选颜色也会保留在 SVG、PNG 和 PDF 导出中。
3. 「（未设置）」标签对应没有该属性的节点，可以用来检查哪些节点还没补全信息。
4. 点击节点会弹出详情卡，列出它的全部属性。节点名称、元素类型、ID、当前匹配和各个自定义属性旁均有「复制」按钮，可复制该字段的完整值，并显示复制结果；字段为空时按钮不可用。按 Esc 或点击空白处关闭。
5. 流程图窗口底部和右侧分别有横向、纵向滚动条，可拖动滑块浏览长图。滚动条与画布的缩放、拖动和「适应窗口」同步，也可聚焦滚动条后使用方向键滚动。
6. 点击连线上的文字或带文字的连线，可打开「连线文字」卡片，完整文本会自动选中。可按 Ctrl+C（Mac：⌘C）复制、选取部分文字复制，或点击「复制文本」按钮；原文的换行会保留。按 Esc、点击空白处或卡片中的「关闭」可关闭。
7. 顶部「深色模式 / 浅色模式」按钮可切换界面与流程图配色，并记住选择。泳道底色、滚动条和详情卡会随模式切换；图形导出采用浅色配色。
8. 点击连线或连线文字时，对应线条会加粗、发光，并标出连线文字；无文字的连线也可选中。点击其他连线会切换选中对象，点击节点、空白处或按 Esc 可取消；选中提示不进入图形导出。

查看器的全部依赖（bpmn-js 17.11.1）都放在本地，**不需要联网**。

### 按属性查看纵向泳道

在顶部「泳道分类」下拉框中选择「来源流程」「责任主体」「元素类型」等属性，即可按不同标签显示纵向泳道。此设置与高亮筛选相互独立，可以在泳道视图中继续筛选、查看详情和复制字段。

- 每个标签对应一条泳道，未设置属性的节点单独归类；多标签节点按原属性中的第一个标签归类，不重复显示节点。
- 仅调整节点的横向位置，保持原有纵向位置。位于同一高度附近的节点会在泳道内分列，泳道宽度按内容调整；展开子流程及其内部节点、边界事件按所属节点整体横移。
- 泳道标题栏固定在视图区域顶端，向下滚动时保持显示，横向滚动或缩放时与对应泳道同步对齐。标题栏仅显示名称，不显示节点数量，采用 28px 单行高度和紧凑的左右调整按钮。
- 在泳道标题右侧点击 ◀ / ▶ 可调整左右顺序，也可聚焦按钮后按 Enter 或空格操作。不同分类属性的顺序在当前文件打开期间分别保留。
- 连线采用水平、垂直线段组成的正交路径，随节点移动和泳道换序重新布线，尽量避开节点；连线文字随路径调整。泳道采用不同的淡底色，顺序调整标签与筛选标签等高。
- 点击「恢复原布局」可回到原始图形位置。视图调整不改写 BPMN 文件；SVG、PNG 和 PDF 导出采用当前视图，包含泳道标题与边框，不包含调整按钮。

### 导出 SVG / PNG

打开 BPMN 后，点击工具栏的「导出 SVG」或「导出 PNG」即可下载完整流程图，不受当前缩放、平移位置和纸张大小限制。两种格式都保留中文、连线和当前筛选高亮，不包含工具栏和节点详情卡；文件名沿用 BPMN 文件名。

- **SVG**：矢量图，可无损放大，推荐用于纵向很长或规模很大的流程图。可直接用浏览器打开，也可放入支持 SVG 的文档或绘图工具。
- **PNG**：白色背景，优先以原始图形的 2 倍分辨率生成。长图会在画布尺寸和内存限制内调整分辨率，并显示实际像素尺寸；如果无法保留至少原始分辨率，会提示改用 SVG，避免导出模糊的缩略图。

导出功能完全离线运行，无需新增依赖。要导出全部节点的正常颜色，可先点击「清除筛选」。

### 打印 / 导出 PDF

打开 BPMN 后，点击工具栏的「打印 / PDF」，查看完整流程图的打印预览，可选择 A4 / A3 纸张和自动 / 横向 / 纵向。点击「打印 / 保存 PDF」，在浏览器打印窗口中选择「另存为 PDF」（或系统 PDF 打印机），建议关闭页眉和页脚。

流程图会等比缩放到一页，保留当前筛选高亮，不受查看器缩放和拖动位置影响；工具栏和节点详情卡不会打印。输出使用矢量 SVG，放大后仍清晰；大流程图可选择 A3 改善阅读体验。此功能完全在本地浏览器运行，双击 HTML 和通过 Python 启动均可使用，无需安装额外依赖。

### 节点属性的格式

属性写在节点的 `extensionElements` 中。同一个属性有多个取值时，就重复写同名的 `property`：

```xml
<bpmn2:manualTask id="..." name="部门领导审核">
  <bpmn2:extensionElements>
    <b2g:properties xmlns:b2g="https://github.com/lxy34232/BPMN2GraphML/properties">
      <b2g:property name="负责人" value="部门领导"/>
      <b2g:property name="信息系统" value="OA"/>
      <b2g:property name="信息系统" value="科研管理系统"/>
    </b2g:properties>
  </bpmn2:extensionElements>
</bpmn2:manualTask>
```

文件中出现的任意属性名都会自动出现在筛选列表中。Camunda/Zeebe 的 `camunda:properties` / `zeebe:properties` 结构相同，也能识别。

合并模式输出 BPMN 时，会自动给每个节点写入「来源流程」属性，取值为它来自哪些原文件。各原文件节点上已有的属性在合并时全部保留。

## 属性表：用 Excel 批量补全节点属性

先从 BPMN 导出一张表，在 Excel 或 WPS 里填写，再导回 BPMN。合并前的原文件和合并后的文件都可以这样处理。

图形界面：打开「属性表」页签，添加 BPMN 文件，点「导出表格…」；填好后点「导入表格…」。导入完成后，可以点「在查看器中打开」查看结果。

命令行：

```bash
python -m bpmn2graphml props-export 科技创新平台策划.bpmn 科技创新平台申报.bpmn -o 属性表.xlsx
python -m bpmn2graphml props-import 属性表.xlsx 科技创新平台策划.bpmn 科技创新平台申报.bpmn
```

### 表格结构

| 节点名称 | 所在文件 | 元素类型 | 负责人 | 信息系统 |
|---|---|---|---|---|
| 部门领导审核 | 科技创新平台策划；科技创新平台申报 | 人工任务 | 部门领导 | OA；科研管理系统 |

- 第一列是节点名称，每个名称一行。名称为空的节点（例如网关）不出现在表中。
- 「所在文件」「元素类型」「来源流程」是只读参考列（灰底），导入时忽略。
- 其余每一列是一个属性，**列标题就是属性名**。想加新属性，就在右边新加一列。
- 一个格子里有多个取值时，用分号分隔，中文“；”和英文“;”都可以。
- 不同文件中的同名节点只占一行，导入时写入所有同名节点。导出时如果它们的取值不一致，会合并显示，并在导出结果中提醒。
- 会被合并展开的空子流程（例如策划流程中的「科技创新平台申报」）在三个文件一起导出时，归到目标流程开始事件（「启动平台申报」）那一行。

### 导入规则：以表格为准

- 格子有值：写入；格子为空：删除该属性；整列删掉：删除该属性；新加的列：成为新属性。「来源流程」不受影响。
- 表中没有的节点不做任何修改，会在报告中列出。
- **直接修改所选的 BPMN 文件**。修改前，原文件会复制为 `原文件名.bpmn.bak`；每次导入都会覆盖上一次的备份。只修改真正有变化的文件，文件中与属性无关的内容（泳道、注释、其它扩展信息等）保持不变。
- 以下情况会中止导入，一个文件都不改：表中有重复的节点名称、重复的列标题、列标题为空但下面有数据、某行没有名称却填了属性、表中一个属性列都没有、表格或 BPMN 文件无法读取。
- 报告显示在界面中，同时保存为表格旁边的 `表格名.import-report.txt`。报告列出修改了哪些文件、每个节点新增/修改/删除了哪些属性、表中找不到的名称，以及表中没有的节点。

### 注意

- 推荐使用 .xlsx。CSV 在 Excel 中打开再保存时，可能把“001”变成“1”、把“1-2”变成日期。
- 导出的 .xlsx 中单元格都是文本格式，填写的内容会原样保留；如果自己新建了表格，需要原样保留的编号、百分比等，请先把单元格设成“文本”格式。日期格式的单元格会读成 `2026-10-20` 这样的形式。
- 只读取第一个工作表；不支持老格式 .xls。

## 已知限制

- 不支持泳池/泳道、消息流、数据对象、注释（读取时会忽略，并给出警告）。
- 非空子流程的内部内容会原样保留，但不会在 yEd 中展开显示。
- 新增元素的 ID 格式为 `EBPM_<uuid>`。
